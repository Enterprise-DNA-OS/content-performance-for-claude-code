# Why this is a database and an editorial desk

The recurring jobs are a morning story review, a weekly section comparison, an evergreen refresh list, due actions and a record-quality check. A trusted operator can do each by asking an agent to run the CLI. Reports are read-only HTML snapshots branded through brand.json. They do not edit the records.

A browser application provides live charts, a publisher overlay, collaborative workflows and immediate interaction. This base does not provide those screens, mobile/offline editing, tracking infrastructure or headline experiments. It imports aggregate exports and keeps the editorial response alongside them. The source tracking service must continue, or a replacement measurement feed must be installed, for fresh metrics after a switch.

Ask for a new read-only view with /new-view. Ask /customise to add your editorial fields, publication thresholds or follow-up rules. Enterprise DNA can build and operate a custom version, including a connected measurement source and a web view, through Omni by Enterprise DNA.
