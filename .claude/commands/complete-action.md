# complete-action

Read docs/cli.md. Read the affected record first. Use the operator's actual evidence. Resolve ambiguous names before writing.

Run:

```bash
npm run content -- complete-action --action=<code> --completed=YYYY-MM-DD --evidence="<evidence>" --actor="<operator>"
```

Use --json for full values when the human output is trimmed. Never invent data or quietly change reporting scope.
